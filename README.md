# Social Media App

A full-stack social media web application built with React.js, Node.js, Express.js, and MongoDB.

The project demonstrates how a modern frontend communicates with a backend REST API and how application data is stored and managed using MongoDB.

---

## 🚀 Features

- User registration and login
- User profile management
- Social media style application interface
- REST API based frontend-backend communication
- MongoDB database integration
- Backend API using Node.js and Express.js
- React.js frontend
- Responsive user interface
- Organized frontend and backend architecture
